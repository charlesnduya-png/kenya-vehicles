# Kenya Vehicles — multi-dealer car marketplace

Kenya Vehicles helps buyers find cars from dealers across Kenya and compare car loan options from banks, saccos, microfinance, and fintechs in one place.

## Features

- Browse and filter cars by county, body type, price, and keyword
- Dealer directory with verified badges and per-dealer inventory
- Car detail pages with enquiry forms and finance estimates
- Loan partner comparison with monthly payment calculator
- Join flows for dealers and lenders

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Stack

- React + TypeScript
- Vite
- React Router
